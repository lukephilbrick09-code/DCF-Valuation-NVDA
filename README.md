This project evaluates NVIDIA's estimated intrinsic value using historical financials, forecast assumptions, UFCF, WACC and terminal value.

The analysis focuses on the key assumptions behind the valuation, the resulting implied share price, and the potential upside or downside compared with the market price.

## Tools

- Excel
- Financial modelling
- DCF valuation
- Financial statement analysis
